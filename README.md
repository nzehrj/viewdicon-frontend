# Viewdicon — Frontend

A large-scale React and TypeScript application built across a multi-phase project, featuring a comprehensive component library, complex authentication, and animated interfaces.

## Tech Stack
- React
- TypeScript
- Redux Toolkit (state management)
- Framer Motion (animations)

## Highlights
- 50+ reusable, well-structured components
- Complex authentication and authorization flows
- Global state management with Redux Toolkit
- Maintained a strict zero-TypeScript-error standard for reliability
